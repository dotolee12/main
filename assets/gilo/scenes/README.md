# Gilo scene illustrations

Production originals belong in this directory as transparent 1024 x 1024 PNG files.

- Do not mirror, crop, recolor, or resize another scene to fill a missing file.
- Keep at least two of expression, pose, action, and prop distinct between scenes.
- Keep the source master outside this folder at `assets/gilo/reference/gilo_master_front.png`.
- Missing files are intentional during rollout; the UI hides the illustration and logs its path once.

The first production batch is listed in `GILO_IMAGE_PROMPTS.md`.
