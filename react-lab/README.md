# GILOA React Lab — 걸은 길과 탐험 메모

길로아 원본의 지도·경로·안개 개념을 React + TypeScript 컴포넌트로 옮긴 첫 번째 수직 기능 구현입니다. 기존 `index.html`, `script.js`, Android, Service Worker, 사용자 데이터 저장 키는 수정하지 않습니다. 전체 길로아 기능 이관 완료판이나 기존 APK 업데이트가 아닙니다.

## Windows에서 여는 방법

1. 이 브랜치의 코드를 내려받아 압축을 풉니다.
2. Node.js **24.22 이상**을 설치합니다. (`node:sqlite` 사용)
3. `react-lab` 폴더에서 우클릭 → **터미널에서 열기**를 선택합니다.
4. `npm ci` 실행 후 `npm run dev`를 실행합니다.
5. 지도 키는 원본 `config.js`의 CARTO 브라우저 키를 읽어 로컬 `.env.local`에 설정합니다(커밋 제외). 해당 키의 허용 출처에 localhost가 없으면 지도가 표시되지 않으며 본인 CARTO 브라우저 키 설정이 필요합니다.
6. Chrome 또는 Edge에서 **http://127.0.0.1:5173** 을 엽니다. HTML 파일을 더블클릭하는 방식은 아닙니다.
6. **걸은 길 기록 시작**을 누르고 위치 권한을 허용합니다. 기록을 멈출 때 **기록 종료**를 누릅니다.
7. 지도에서 장소를 선택해 메모를 저장합니다. 종료는 터미널에서 `Ctrl+C`입니다.

개발 서버는 기본적으로 이 컴퓨터에서만 접근할 수 있습니다. 휴대폰의 `localhost`는 PC가 아니므로 휴대폰 실보행 시험에는 별도 HTTPS 테스트 배포가 필요합니다. IP 주소로 HTTP 접속하면 위치 권한이 제한될 수 있습니다.

## 구현 범위

- `src/useTracking.ts`: 명시적으로 시작한 브라우저 GPS 구독·종료, 오류 처리
- `src/tracking.ts`: 15m 이동 필터, 최대 100m 오차 필터, 비정상 순간 이동 필터, GPS 공백 구간 분리, 거리 계산, GPX 출력
- `src/Map.tsx`: Leaflet 지도, 현재 위치·오차 원, 이동 경로, 경로 주변 18m 안개 제거 Canvas
- `src/main.tsx`: 기록 상태·거리·안개 토글·GPX 내보내기, 장소 메모 CRUD
- `src/i18n.ts`: 한국어·영어·일본어·중국어
- `server/api.ts`: SQLite 메모 REST API, 서버 입력 검증, 파라미터 바인딩, 동일 출처 검사
- `server/index.ts`: 로컬 HTTP 서버와 Vite 개발 화면 연결

### 저장 경계

| 데이터 | 저장 위치 | 원본 데이터 접근 |
| --- | --- | --- |
| 새 GPS 경로 | 이 실험판 브라우저의 `giloa-react-lab-trail-v1` 키 | 원본 길로아 키를 읽거나 수정하지 않음 |
| 직접 입력한 장소·메모·선택 좌표 | `react-lab/data/notes.sqlite` | 원본 길로아 DB·계정에 연결하지 않음 |
| 지도 타일 | CARTO / OpenStreetMap 외부 요청 | 보이는 지도 영역의 타일 요청 발생 |

위치 추적 기록은 메모 백엔드로 보내지 않습니다. 브라우저 데이터를 지우면 새 실험판 경로가 없어질 수 있으므로 중요한 경로는 GPX로 내보내세요. DB 파일을 삭제하면 실험판 메모가 없어지므로 보존하세요. 이 실험판은 1인 로컬 사용 기준이며 로그인·다중 사용자 격리·공개 서버 운영 준비는 포함하지 않습니다. 지도 요청은 외부 서비스로 나갑니다.

재실행하면 저장 경로를 복원하지만 위치 추적은 자동으로 재개하지 않습니다. GPS가 120초 넘게 끊기거나 다시 시작하면 별도 구간으로 기록합니다. GPS 오차·브라우저 한계 때문에 실제 이동을 빠짐없이 기록한다고 보장할 수 없습니다.

## 중요한 미이관 기능

- 기존 Android 네이티브 백그라운드/잠금 화면 GPS 서비스와 bridge
- 8시간 장시간 기록 검증
- 기존 GPX 가져오기·사진·EXIF·HEIC·관광 API·배지·지역 체류·성장 기능
- 기존 저장 자료 마이그레이션, PWA/Service Worker, 기존 계정 동기화

이 항목들은 기존 원본에 그대로 있으며, 이 실험판으로 대체하지 않습니다. 화면이 꺼지거나 브라우저가 백그라운드로 가면 GPS 구독이 멈출 수 있습니다. 안드로이드에서 원본의 장시간 기록을 대체하려면 기존 네이티브 수집기를 연결하고 장시간 시험해야 합니다.

## 검사 및 재현

```sh
npm test
npm run build
npm start
```

- PASS: TypeScript strict 검사, Vite production build
- PASS: 경로 이동·오차·순간 이동 필터, GPS 공백 구간, 거리, JSON 경로 복원, GPX 구간 생성 자동 테스트
- PASS: 메모 생성·조회·수정·삭제, SQLite 재연결 후 보존, 잘못된 입력·교차 출처 거부 자동 테스트
- PASS: 브라우저 메모 생성·수정·삭제, 새로고침 후 보존, 한국어·영어 표시
- 미검증: 실제 실외 GPS 이동, 권한 거부 후 복구, 경로 실제 이동 UI·안개 제거 시각, GPX 파일 외부 앱 불러오기, 8시간/잠금 화면 기록, 일본어·중국어 화면 시각 검증
- 원본 GPS·사진·EXIF·TourAPI·PWA 회귀: 원본 소스 변경 없음 확인. 원본 실제 기기 동작은 미검증.

지도에 가짜 이동 흔적을 넣지 않습니다. 자동 테스트용 좌표는 테스트 파일에만 있으며 실제 저장 데이터에 들어가지 않습니다. SQLite 실행 시 Node의 experimental 경고가 표시될 수 있습니다.
