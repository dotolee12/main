계정 보호

길로아에서 기록이 어떻게 구분되고, 사용자가 어떤 방식으로 자신의 기록을 지킬 수 있는지 안내합니다.

최종 수정일: 2026년 8월 3일

1. 기록 구분 방식

길로아는 사용자가 입력한 길로아 아이디를 기준으로 사진, 방문 장소, 발걸음 기록을 구분합니다.

같은 기기와 브라우저에서 같은 아이디를 사용하면 해당 아이디의 기록을 다시 확인할 수 있습니다.

2. 기기와 브라우저 보호

  • 공용 기기에서는 사용 후 길로아 아이디를 변경하거나 브라우저 사이트 데이터를 삭제해 주세요.
  • 브라우저 저장 데이터가 삭제되면 기기 안에 있던 일부 기록이 함께 사라질 수 있습니다.
  • 중요한 이동 경로는 GPX 파일로 따로 저장해 두는 것을 권장합니다.

3. 위치와 사진 권한

위치 권한과 사진 접근 권한은 지도 기록, 사진 표시, 뱃지 조건 확인을 위해 사용됩니다.

권한은 기기 또는 브라우저 설정에서 언제든 변경할 수 있습니다.

4. 도움이 필요할 때

계정이나 기록 접근에 문제가 있다면 고객지원 페이지로 문의해 주세요.
