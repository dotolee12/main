길로아 메뉴 통합 수정본

수정 내용
1. 기억 탭 제거
2. 사진 기록 탭이 기억 역할을 대신함
3. 사진 지도 팝업에 '이 사진을 남긴 이유' 입력란과 저장 버튼 추가
4. 사진 목록에 입력한 이유 표시
5. 뱃지 탭 제거
6. 획득한 뱃지는 아이템 목록 안에 함께 표시
7. 하단 메뉴는 방문 / 아이템만 유지
8. 햄버거 메뉴 안에 개인정보처리방침 / 이용약관 / 고객지원 연결

설치 방법
- 기존 app 폴더 안의 같은 이름 파일을 백업합니다.
- 이 폴더의 파일을 app 폴더에 덮어씁니다.
- GitHub에 업로드 후 브라우저에서 강력 새로고침합니다.

주의
- vendor, images, tm-my-image-model 등의 기존 폴더는 삭제하지 마세요.
- config.js에는 실제 API 키가 있으므로 공개 저장소 보안에 주의하세요.
