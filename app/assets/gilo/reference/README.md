# Gilo master reference

Place the approved transparent, front-facing neutral character at:

`assets/gilo/reference/gilo_master_front.png`

This exact file must be attached to every image-generation request. The current
`images/giloa-guide-character-transparent.png` is only a candidate source: it is
683 x 900 and its background is opaque green, so it is not the approved master.

Approval checklist: transparent alpha, neutral front view, full body and tail,
unobstructed ears/pendant, 1024 x 1024 canvas, generous margin, no text/UI/shadow.
