# 사진 아이템 자동 판별

기능을 수정하기 전에 루트 `FEATURE_MAP.md`와 `GILOA_CORE_RULES.md`를 읽는다.

## 담당 파일

| 파일 | 역할 |
|---|---|
| `photo-items.js` | 사진 선택 후 자동 판별 시작, 결과 표시, 아이콘·빈 이름 제안, 사용자 확인 후 저장 |
| `item-recognition.js` | 사진을 최대 640px로 줄여 임시 Worker에 전달, 확신도·크기·위치·경쟁 결과 판단, 취소·시간 초과 |
| `item-recognition-worker.js` | 독립된 CPU Worker에서 모델을 내려받아 추론. 기존 길로아 전역 `tf`와 분리 |
| `item-icons.js` | 직접 만든 기본 그림 아이콘과 이름 기반 보조 제안 |
| `tests/item-recognition.test.cjs` | 결과 선별, 취소, 제한된 픽셀 전달, 오류 처리 |
| `tests/photo-items.test.cjs` | UI 자동 선택, 이름 보존, 수동 선택 보호, 저장·복원 |

## 실제 흐름

사진을 촬영하거나 선택하면 기기 내에서 물건을 판별한다. 지원하는 종류가 충분히 확실하면 기본 그림 아이콘을 선택하고, 이름이 비어 있을 때만 해당 언어의 이름을 채운다. 이미 입력한 이름은 덮어쓰지 않는다. 저장은 사용자가 확인하고 누른 뒤에만 이루어진다.

기존 사진 아이템도 `아이콘 변경`으로 열면 저장된 작은 사진을 판별한다. 이미 그림 아이콘인 SVG는 다시 사진 인식에 넣지 않는다. 아이템 ID와 생성 날짜는 유지한다. 자동으로 모든 기존 아이템을 바꾸거나 삭제하지 않는다.

직접 종류를 고르면 진행 중인 분석을 취소한다. 사진 교체·창 닫기·페이지 종료도 Worker를 종료한다. 늦게 온 결과가 새 사진이나 수동 선택을 덮어쓰면 안 된다. 판별이 애매하거나 도구 로드에 실패하면 직접 선택·사진 자르기는 계속 사용할 수 있다.

## 지원 범위

COCO-SSD의 모든 분류가 길로아의 그림 아이콘과 일치하는 것은 아니다. 현재 자동 연결은 휴대폰, 책, 컵·병 등 음료 용기, 배낭·핸드백·여행 가방, 자전거, 자동차, 일부 음식이다. 기본 아이콘에서 선택 가능한 카메라·꽃·나무·건물 등이 모두 자동 인식된다고 안내하지 않는다.

최소 확신도 0.60, 최소 면적 2%를 적용한다. 비슷하게 유력한 서로 다른 종류가 있으면 자동 선택하지 않는다. 이 기준을 낮춰 맞힌 것처럼 보이게 하지 않는다. 사진 속 물체를 새로 그리거나 그 물체 고유 외형을 보존하는 생성형 AI가 아니라, 지원 종류에 맞는 기존 그림을 고르는 기능이다.

## 사진·통신·저장

- 사진의 픽셀은 페이지와 임시 Worker 안에서만 처리한다. 모델 제공자에게 사진·위치·이름을 전송하지 않는다.
- 최초 인식에는 인터넷이 필요하다. 고정된 버전의 실행 도구와 공개 모델 파일만 GET으로 내려받는다. 이후 재사용 여부는 브라우저 HTTP 캐시에 따라 달라지므로 완전 오프라인을 보장하지 않는다.
- TFJS 4.22.0과 coco-ssd 2.2.3을 jsDelivr에서, `ssdlite_mobilenet_v2` 모델을 Google Cloud Storage에서 읽는다. 모두 인식 요청 후 Worker에서만 로드한다. 사진 선택 전 지도 실행 시 미리 내려받지 않는다.
- Worker는 최대 90초 제한 후 종료하며, 성공·오류·취소 시에도 해제한다. CPU를 별도 Worker에서 사용해 기존 사진 인식 TensorFlow 버전과 충돌하지 않게 한다.
- 그림 아이콘 모드에서는 SVG 아이콘과 이름만 기존 아이템 저장소에 저장한다. 인식용 전체 사진이나 픽셀을 추가로 저장하지 않는다. 사진 모드를 직접 선택한 경우에만 잘라낸 사진을 저장한다.

- 공식 설명·지원 분류: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd
- TensorFlow.js: https://github.com/tensorflow/tfjs (Apache-2.0)
- coco-ssd 및 모델 변환 소스: https://github.com/tensorflow/tfjs-models (Apache-2.0)
- 실행 도구 URL은 Worker 코드에 버전과 함께 고정돼 있다. API 키나 외부 이미지 분석 서버는 사용하지 않는다.

실제 브라우저 확인에는 Wikimedia Commons의 Jakez 촬영 `Samsung mobile phone.jpg` (CC BY-SA 3.0) 사진을 임시로 사용했다: https://commons.wikimedia.org/wiki/File:Samsung_mobile_phone.jpg . 시험 사진은 제품 소스·배포 파일에 포함하지 않는다. 단위 테스트는 가상 픽셀·가상 결과로 경계 동작을 검증하며, 이 통과를 실제 카메라 인식 정확도 검증으로 표현하지 않는다.
