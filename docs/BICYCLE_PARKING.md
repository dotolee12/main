# 자전거 주차 자동 기억

길로아 ☰ → 자전거 자동 기억 → 자동 기억 켜기. 기존 위치 기록도 시작해야 합니다. 자전거를 탈 때 켜고 사용 후 끕니다. 서버에 위치를 보내지 않으며 기존 여행·사진·소지품 기록은 변경하지 않습니다.

GPS 속도 2.5~12m/s가 최소 60초·5개 표본 이어진 다음, 0.5~2.2m/s의 도보가 최소 60초·5개 표본과 25m 이동을 충족하면 최초 저속 위치를 주차 후보로 저장합니다. GPS 오차 30m 초과는 제외합니다. 90초 넘게 기록이 끊기면 판정을 리셋합니다. 정차만으로는 생성하지 않으며, 정차 뒤 도보가 시작되기까지 최대 10분을 허용합니다. 속도가 없는 표본에서는 추측하지 않습니다.

속도는 이동수단의 증명이 아닙니다. 느린 자동차, 달리기, GPS 오차는 오판을 일으킬 수 있습니다. 후보와 위치 오차·시각을 보고 확인하거나 지울 수 있습니다. 미확인 후보는 새 후보로 덮어쓰지 않습니다. 확인한 위치는 다음 이동 뒤 새 후보로 갱신됩니다. 자전거가 다른 사람에 의해 이동해도 따라가지 않습니다.

웹: 실행 중 들어오는 위치만 분석합니다. 화면 잠금·탭 종료 시 보장하지 않습니다.
안드로이드: 기존 RouteTrackingService가 수집한 위치를 앱 복귀 시 순서대로 분석합니다. 서비스 자체·권한·서명·패키지는 변경하지 않습니다. 기존 설치 앱의 assets 업데이트는 별도 정식 서명 APK가 필요합니다. 이 작업에서 APK를 생성한 것은 아닙니다.

전용 localStorage `giloa-bike-parking-v1`에 설정, 작은 감지 상태, 최신 후보 하나를 저장합니다. 꺼도 기존 후보는 유지합니다. 브라우저 데이터 삭제·다른 기기에는 이전되지 않습니다.

자동 검사: 감지·정차·단절·속도누락·네이티브 순서재생·메뉴·저장·확인·지도찾기·번역·기존 저장 키 보존.
실제 자전거 이동, 화면 잠금 수집, 기존 APK 위 업데이트 설치, 실내 GPS 정확도는 미검증입니다.
